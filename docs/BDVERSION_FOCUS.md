# MAW-bd 产品范围（唯一需求基线）

## 目标流水线

```text
视频
  → Qwen ASR（主：qwen-audio-3.0-asr-flash-filetrans；副：qwen3-asr-flash-filetrans）
  → 原文稿对齐（本地顺序单调；TXT/MD/DOCX/粘贴）
  → DeepSeek 保守校对（语音优先；corrected 默认不自动覆盖 text）
  → 校验状态 + 既有五色
  → MAWE 编辑（核心能力 + proofread 过滤/manual）
  → SRT（仅最终字幕）
  → FCPXML（本地网页 web/srt2fcpxml-page，MIT GanymedeNil/srt2fcpxml）
```

## 约束

- 语音是真源；文稿只作错字/专名参考
- `.mosp` 毫秒契约；旧工程可打开
- 服务仅 `127.0.0.1`
- macOS 交付：`dist/MAW-bd.app`（PyInstaller）
- 不手改 `blank-editor.html`

## 决策（已确认）

1. DeepSeek 不自动覆盖 `segments[*].text`
2. `manual` 不自动上色
3. 包名模块：`maw/bdversion`
4. FCPXML：本地转换网页（非 Python 主路径）
5. 新流水线 Launcher 默认关闭

### 波形快捷切割

鼠标停在波形字幕块上会显示剪刀与切割线，按默认 B 键直接在该线的整数毫秒位置切割，不打开文字断点窗口。主字幕列表悬停显示文字断点，同样可直接切割；鼠标不在字幕块上时使用当前播放头切割主字幕；距两端不足 100ms 时提示移动切点。拆分后可撤销。

「设置 → 通用操作 → 编辑快捷键」可配置分割、合并、新建、起点和终点键，点击「自定义」后采集单键或组合键，单独按修饰键继续等待；可取消采集。编辑动作之间冲突时互换，支持恢复默认。在字幕区域，自定义组合键优先于原有快捷键。配置保存在当前编辑器的本地设置中。

文字分配优先使用完整对齐、顺序有效的字词时间码；旧工程缺少可靠时间码时仅估计文字位置并寻找附近词边界，不将估算位置写成字级时间。英文单词、版本号、URL 和数字量词组合不在内部直接切开。

### 校验详情与光标切割

选中字幕不再自动展开校验详情。悬停或键盘聚焦字幕前的 V/I/U/M 徽标，可查看文稿、原始 ASR、副 ASR、校对建议与原因；原识别差异以红色标出，校对后差异以绿色标出。鼠标可移入浮窗阅读，离开、按 Esc 或滚动字幕列表后关闭。

双击波形字幕块的小编辑窗提供「在光标处切割」：将文字光标放在所需断点后点击，直接生成两条字幕。优先使用字词时间码；修改后不复用失效的字词时间码。文字修改与切割可一次撤销。已移除主字幕编辑区的播放头切点预览，非悬停字幕时的快捷键时间切割保持不变。

### 导出格式参考

FCPXML 导出窗口显示当前视频的分辨率和帧率，分数帧率保留原始比值。读取不到时明确提示，不用工程时间基准或导出默认值冒充源视频参数；导出参数仍由用户选择。分辨率选项标注宽高比：1920 × 1080 和 3840 × 2160 为 16:9，1080 × 1920 为 9:16 竖屏，2880 × 2160 为 4:3。

### 本地模型准备

本地识别设置提供「下载 / 检查本地模型」，按当前引擎预加载 Qwen3-ASR 1.7B（含 forced aligner）、FunASR paraformer-zh 或 faster-whisper large-v3。沿用上游独立 Runtime 预加载方式，复用识别缓存，不自动安装运行时。首次可能需要数 GB，日志显示加载器输出和等待时长；停止可取消，已完成缓存保留，不承诺单个临时文件字节级续传。

### 开头删除合并

主字幕文字编辑框、双击小编辑窗和主字幕列表内联编辑时，光标在第一个字符前且没有选择文字，按 macOS Delete（Backspace）与同轨上一条合并，光标停在连接处，可继续编辑和撤销。第一条不合并；选中文字、普通删字、向前删除、修饰键和输入法组合输入保持原有行为。当前草稿先保存，再按既有合并逻辑处理时间范围、字词时间码和颜色引用；草稿修改与合并分别可撤销。

## 校对审查与字幕空隙

Launcher 校对生成建议工程后不弹审查页、不提供审查入口；审查仅在字幕编辑器页面进行。建议默认未勾选，勾选的采用建议，未勾选的保留本次校对前原文。取消不应用。编辑器工具栏“校对审查”可再次查看、采用或拒绝，修改可撤销。人工修改的字幕锁定，校对不覆盖它。审查保持字幕数量、顺序、时间、items 和颜色不变，SRT 仅输出最终选择的文字。

“校对”筛选含 LLM 校对修改、阿拉伯数字、英文、标点；标点采用 Unicode 标点分类，支持中英文，空白和 emoji 不算标点。审查页内容筛选检查原文与建议，切换筛选保留勾选。

“批量操作 → 消除字幕空隙”填写最大空隙（整数毫秒，默认 200），预览符合条件的正空隙，选择全部主字幕或所选相邻字幕。只延长前一条结束时间到下一条起点，不移动音频或删除媒体，不合并文字，真实字词时间码保留，可撤销。禁用项、重叠、非相邻选择跳过。

“批量操作 → 高亮短字幕空隙”设置阈值（默认 200ms），只高亮大于零且严格小于阈值的主字幕空隙，等于阈值不标出。可独立关闭，设置记在本机，工程和媒体不变。

设置中的编辑快捷键可自定义 W/A/S/D 四个导航动作；点击自定义并按键采集，冲突互换，帮助提示同步。默认 Shift 扩展选择，按住字幕块时继续支持向左/右微调，文本输入与弹窗不触发全局导航。

### 本地模型缓存与网络

Qwen 识别与“下载 / 检查本地模型”共用完整缓存检查，配置、处理器、分词器及全部 safetensors 分片就绪时直接用本地 snapshot 目录，ASR 与 ForcedAligner 都不再按仓库 ID 联网查询。缺失或损坏的文件不会被视作下载成功；需要下载时默认国内 hf-mirror.com，失败回退 huggingface.co，保留已下载缓存。显式 HF_ENDPOINT 使用用户指定下载源；公开模型下载不向镜像传递 Hugging Face 凭据。

“含空格”筛选匹配 Unicode 空格（半角、全角和不换行空格）；换行及制表符不算空格。只在字幕筛选菜单显示，按最终文字筛选；校对审查页不提供空格筛选。

### 简明进度与日志

界面日志仅显示关键准备、模型加载、识别、完成、回退与报错；模型库调试、重复重试和 LLM 正文不显示。校对开始与结束仍显示，完整修改通过审查页查看。准备模型及不可测量的识别/校对过程显示进行中，不把内部阶段数值当真实百分比。分块 ASR 用实际已完成段数更新进度，并显示当前段数；完成、失败明确标注。

### Mac 本地识别精度

Qwen ASR 和 ForcedAligner 在 MPS 上均使用 FP32，避免两个模型共同加载时低精度推理产生空文本或无关的多语言字符；CUDA 保留 FP16，CPU 保留 FP32。全精度会增加内存占用，加载失败仍按原有规则回退 CPU。无需重新下载权重，缓存和毫秒时间契约不变。

### 新增控件外观

校对审查、字幕空隙弹窗统一使用原 MAWE 设计令牌与浅色/深色主题；原文与建议并排展示，窄窗口自动上下排列。快捷键设置按名称、按键、自定义按钮对齐。新增按钮、菜单、聚焦和禁用状态复用原编辑器样式。
