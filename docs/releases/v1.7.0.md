# MAW-bd v1.7.0

## 下载哪个版本？

- **macOS 🍎（Apple Silicon）**
  - 首次安装：[MAW-bd-1.7.0-macOS-arm64.zip](https://github.com/Swing233/MAW-bd/releases/download/v1.7.0/MAW-bd-1.7.0-macOS-arm64.zip)
  - 已安装 1.6.2：可在应用内选择增量更新，无需自行下载增量包。

此安装包适用于搭载 Apple 芯片的 Mac，内置 FFmpeg / FFprobe。首次使用本地识别仍需联网准备运行环境和模型。

## 如何使用

1. 下载完整安装包并解压，将 `MAW-bd.app` 放入「应用程序」。
2. 双击打开应用，选择要处理的视频或音频。
3. 完成语音识别，按需添加文稿进行校对。
4. 打开字幕编辑器，检查文字和时间，保存工程并导出字幕。

已有字幕时，可使用「MP4 + SRT 直接编辑」，跳过识别步骤。

详细操作见 [使用教程](https://github.com/Swing233/MAW-bd/blob/main/docs/WORKFLOW.md)，遇到问题见 [常见问题](https://github.com/Swing233/MAW-bd/blob/main/docs/FAQ.md)。教程随开发版本更新，部分新操作会在后续版本提供。

## 1.7.0 更新内容

### 🚀 新增

- 字幕筛选支持 LLM 修改、阿拉伯数字、英文、标点符号和空格。
- 支持消除相邻字幕的短空隙，并高亮指定长度以下的空隙。
- W/A/S/D 导航和微调支持自定义快捷键及组合键。
- 文字光标在字幕开头时，按 Delete 可与上一条字幕合并。
- FCPXML 导出新增 1080 × 1920 竖屏选项，分辨率显示宽高比参考。

### ✨ 优化

- 编辑器中的校对建议可逐条采用、保留原文及撤销，保护人工修改。
- 统一新增控件的样式，支持浅色、深色主题和较窄窗口。
- 简化任务进度和日志，识别时显示当前处理的段数。
- 模型缓存完整时直接离线加载；需要下载时优先尝试国内源。

### 🐛 修复

- 修复 Mac 本地 Qwen 识别出现空文本或乱码的问题，已有模型无需重新下载。修复后本地识别会增加内存占用。

## 安装提示

增量包仅供更新器使用，不能单独安装。当前应用尚未经过 Apple 公证，首次打开的处理方式见常见问题。
