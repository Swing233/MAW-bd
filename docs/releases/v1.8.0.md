# MAW-bd v1.8.0

## 下载哪个版本？

- **macOS 🍎（Apple Silicon）**
  - 首次安装：[完整安装包](https://github.com/Swing233/MAW-bd/releases/download/v1.8.0/MAW-bd-1.8.0-macOS-arm64.zip)
  - 已安装 1.7.0：可在应用内选择增量更新，无需自行下载增量包。

此安装包适用于搭载 Apple 芯片的 Mac。首次使用本地识别需要联网准备运行环境和模型，无需另装原版 MAW。

## 如何使用

1. 下载完整安装包并解压，将 `MAW-bd.app` 放入「应用程序」。
2. 打开应用，选择视频或音频进行识别。
3. 按需添加文稿并校对文字。
4. 打开字幕编辑器，检查内容和时间，保存工程并导出字幕。

已有视频和 SRT 时，可使用「MP4 + SRT 直接编辑」，跳过识别步骤。

详细操作：[使用教程](https://github.com/Swing233/MAW-bd/blob/v1.8.0/docs/WORKFLOW.md) · [编辑器指南](https://github.com/Swing233/MAW-bd/blob/v1.8.0/docs/EDITOR_GUIDE.md) · [常见问题](https://github.com/Swing233/MAW-bd/blob/v1.8.0/docs/FAQ.md)

## 1.8.0 更新内容

### 🚀 新增

- 导入视频时检查帧率和可读取的总帧数，字幕拖动、微调、切割和时间输入默认以帧为单位。
- 字幕列表支持拖动框选，按住 Shift 可追加选择。
- 文本处理支持数字双向转换，以及英文首字母大写、全大写和全小写。选中字幕时只处理选中项。
- 右键菜单增加数字转换、英文大小写、删除空格和删除标点符号，二级菜单悬浮展开。
- 字幕面板设置可关闭回车切分，关闭后按 Enter 保存文字。

### ✨ 优化

- 工具栏按审阅、文字编辑和时间调整整理，文本处理与空隙消除在按钮下方展开小面板。
- 「审阅」支持同时选择多个筛选条件。修改后保持当前结果，便于检查变化；重新选择条件时刷新筛选。
- 跟随播放与空隙高亮放入列表设置，空隙高亮默认开启，阈值为 200ms。
- 数字转中文时，有对应的校对前原文则优先恢复原有数字表达。菜单使用「233→二三三」「二三三→233」说明方向。
- 新工程默认打开「字幕列表编辑」工作区，使用教程与常见问题同步更新。

### 🔄 变更

- LLM 校对默认直接应用修改，保留原始文字和差异记录，可在编辑器恢复原文；人工修改继续受保护。
- 移除独立 LLM 审查弹窗，相关内容统一在「审阅 → LLM 修改」筛选中查看。
- 移除表情包、双语字幕、拼接字幕与静音空隙处理入口，包括全局设置中的残留帮助。保留字幕空隙消除与高亮。

### 🐛 修复

- 修复字幕校验标记导致列表文字错位的问题，使字幕统一对齐。
- 修复 ASR 完成后逗号替换产生重复空格的问题，统一为一个空格。
- 修复 LLM 额外引入中文词间空格的问题，保留原有排版与英文单词分隔。
- 修复 Finder 列表模式下应用图标显示乱码的问题。
- 修复小数帧率下连续逐帧跳转累积误差的问题。
- 修复自定义快捷键影响快速上手练习的问题。

## 安装提示

增量包仅供应用更新器使用，不能单独安装。更新前请保存工程。当前应用尚未经过 Apple 公证，首次打开的处理方式见常见问题。
