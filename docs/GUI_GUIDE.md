# MAW-bd 启动器指南

启动器负责选择媒体、语音识别、文字校对和软件更新。字幕编辑器可以独立打开。第一次制作字幕建议先看 [完整流程](WORKFLOW.md)。本文对应当前开发版本。

## 1. 打开字幕编辑器

- **打开字幕编辑器**：进入空白编辑器，再载入文件。
- **导入工程打开**：选择已有 `.mosp` 或兼容的 `.json` 工程。
- **MP4 + SRT 直接编辑**：选择媒体，准备波形并打开编辑器；旁边有同名 SRT 时自动载入，没有时可进入编辑器后导入。

例如，将 `演示.mp4` 和 `演示.srt` 放在同一目录。首次直接编辑会创建 `演示.maw-edit.mosp`；已有该工程时继续打开原工程，不会重新覆盖它。

## 2. 语音识别

### 本地识别

默认引擎为 **Qwen3-ASR 1.7B**。界面也提供 FunASR paraformer-zh 和 faster-whisper，按实际需要选择。

点击「下载 / 检查本地模型」会检查缓存，并准备缺少的运行环境和模型。首次需要联网，之后复用缓存；无需先安装原版 MAW。

模型准备完成后，点击「开始 ASR」。运行时与模型下载可能持续较久，日志会显示关键进度；需要中止时点击「停止」。

### 云端识别

切换为「云端 Qwen API」，在配置区填入百炼 API Key 并保存。可选模型：

- `qwen-audio-3.0-asr-flash-filetrans`
- `qwen3-asr-flash-filetrans`

云端识别需要网络及可用的服务额度。Key 不写入字幕工程；请勿将密钥或配置文件上传 GitHub。

## 3. 修订字幕

识别后可选「添加文稿」，或者直接粘贴参考文字。文稿只用于纠正可能的识别错误，不替换实际语音。

使用 DeepSeek 时，在配置区填入自己的 Key。默认模型为 `deepseek-flash`。点击「开始修订」，完成后打开修订后的工程。

当前开发版直接应用校对文字；可在编辑器「审阅 → LLM 修改」中筛选，再悬停校验徽标查看原文和原因。人工修改的字幕受保护。

「生成提示词并复制」可用于外部模型校对。导回 SRT 时先核对条数和时间，避免外部模型擅自重新断句。

## 4. 查看进度与日志

右侧日志显示模型准备、识别、校对、完成和报错等关键消息，可收起。下载或模型加载尚无法测量时显示进行中；分块识别显示当前段数。

出错时优先查看最后一条完整错误，处理后再重试，不要同时启动多个识别任务。

## 5. 更新软件

1. 点击「检查更新」。
2. 发现新版后，选择「优先增量更新」或「全量更新」。
3. 根据网络情况选择国内镜像优先或 GitHub 直连。
4. 点击「下载更新」，可查看下载速度、已下载大小和总大小。
5. 下载完成后按界面提示安装，应用会退出、替换并重新启动。

增量更新需要发布方提供适合当前版本的增量包；没有可用增量包时使用完整包。首次安装仍下载完整包。更新需要重启应用，开始前保存字幕工程。

下载失败时可切换线路重试，或从 [发布页面](https://github.com/Swing233/MAW-bd/releases) 下载完整包手动安装。
