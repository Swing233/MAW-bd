# MAW-bd 字幕编辑器指南

本指南对应当前开发版本，按实际编辑顺序介绍：打开工程 → 检查文字 → 调整时间 → 审阅 → 保存导出。首次识别见 [使用教程](WORKFLOW.md)。

## 1. 打开文件

从启动器打开已有工程，或点击「MP4 + SRT 直接编辑」。只有 SRT 时也可以编辑文字，绑定视频后再检查时间和波形。

默认工作区为「字幕列表编辑」。旧工程会恢复保存过的布局。媒体被移动后，需要重新选择媒体；`.mopeaks` 只是波形缓存，不能替代视频。

## 2. 选中与修改

| 操作 | 用法 |
| --- | --- |
| 选中字幕 | 单击字幕行或波形字幕块 |
| 多选 | 在列表或波形空白处按住鼠标拖动；Shift 拖动追加 |
| 修改文字 | 双击字幕，进入文字编辑 |
| 保存小窗修改 | Enter |
| 保存工程 | `Cmd+S` |
| 撤销 | `Cmd+Z` |

波形字幕块上的拖动用于移动字幕；空白处拖动用于框选，不必按 Shift。

## 3. 拆分和合并

### 按位置拆分

默认分割键为 **B**：

- 鼠标在字幕文字上：按字符之间显示的切割线拆分。
- 鼠标在波形字幕块上：按块上显示的位置拆分。
- 鼠标不在字幕块上：按当前音频播放位置拆分。

有可靠字词时间码时优先使用真实时间；没有时只能估计文字与时间的对应关系，拆分后应试听检查。

双击编辑的小窗也提供「在光标处切割」。先把文字光标移到断点，再点击即可。

### 合并

选中连续字幕，默认按 **C** 合并。文字光标在字幕最开头、且没有选中文字时，按 macOS Delete（Backspace）可与上一条合并；第一条字幕不执行合并。

### 修改快捷键

进入「设置 → 通用操作 → 编辑快捷键」，点击「自定义」后按下按键或组合键。支持分割、合并、新建、起止点和 W/A/S/D 导航设置。

字幕面板的「编辑设置 → 操作」提供「关闭回车切分」。开启后 Enter 保存修改，不再触发切分；分割快捷键和光标切割仍可使用。

## 4. 调整字幕时间

导入视频后先读取帧率和可用的总帧数，默认按源视频帧率编辑。拖动、起止点调整、切割和键盘微调以帧为单位，默认每次微调一帧；时间码显示为时、分、秒、帧。工程仍保存兼容的整数毫秒。只有音频或无法读取帧率时使用毫秒，未知帧率可在工程设置中手动指定。

拖动波形字幕块可整体移动；拖动边缘调整起点或终点。操作后播放前后几秒，确认字幕与语音对齐。

「消除字幕空隙」在按钮下方打开小面板，可预览后执行。它延长前一条字幕的结束时间，使其贴合下一条起点，不删除音频，也不合并文字。

「列表设置」中的空隙高亮默认启用，阈值为 **200ms**：大于零且小于阈值的字幕间隔会被标出。高亮只是提示，不改变时间。

## 5. 审阅与筛选

「审阅」集中放置以下条件，可点击多选：

- 校对状态：已校验、现场发挥、待确认、人工修改。
- 字幕内容：LLM 修改、阿拉伯数字、英文、标点符号、空格。
- 长度与可见性：超长字幕、字数阈值、隐藏禁用字幕。

多个校对状态任意满足一个即可；多个内容条件必须同时满足。例如选择「含阿拉伯数字」与「含英文」，只显示两者兼有的字幕。

修改文字后，当前结果保持显示，方便比较修改效果。调整筛选条件后重新筛选；「全部」清除校对状态与内容条件，长度和可见性选项独立控制。

悬停字幕前方的校验徽标可查看参考文稿、原始 ASR、校对文字和原因，差异会高亮。当前开发版默认采用 LLM 校对结果；仍可在详情中保留原文或重新采用建议。

## 6. 批量处理文字

选中字幕后，点击「文本处理」，仅处理选中项；未选中时可处理全部字幕。先预览，再应用，支持撤销。

| 处理方式 | 结果 |
| --- | --- |
| 中文数字 → 阿拉伯数字 | `两个` → `2个` |
| 阿拉伯数字 → 中文数字 | 优先恢复校对前对应的中文表达，如 `2个` → `两个` |
| 每个单词首字母大写 | `hello world` → `Hello World` |
| 全大写 / 全小写 | `Hello` → `HELLO` / `hello` |

缺少可靠原文时，数字转中文采用常规转换，可能得到「二」；应用前检查预览。

右键菜单也提供数字转换、英文大小写、删除空格和删除标点符号。数字与英文菜单悬浮后侧向展开。删除空格会连同英文单词间的空格一起删除，请确认选区。

文字处理不会移动字幕时间。人工改字会标记为「人工修改」。

## 7. 列表显示设置

在「列表设置」中配置跟随播放、自动滚动、序号、时间码、字数列及空隙高亮。跟随播放仅控制列表浏览，不改变字幕。

## 8. 保存与导出

先保存 `.mosp`，再从「导出字幕」选择 SRT 或转换为 FCPXML。

- **SRT**：只保存最终文字与时间，不包含颜色、校对原因和筛选条件。
- **FCPXML**：根据导出窗口显示的源视频参数选择帧率和分辨率，再导入 Final Cut Pro。

| 分辨率 | 宽高比 | 常见用途 |
| --- | --- | --- |
| 1920 × 1080 | 16:9 | 横屏高清 |
| 3840 × 2160 | 16:9 | 横屏 4K |
| 1080 × 1920 | 9:16 | 竖屏视频 |
| 2880 × 2160 | 4:3 | 4:3 画面 |

帧率支持 23.98、24、25、29.97、30、50、59.94 和 60fps。读取不到源参数时，以视频或 Final Cut Pro 工程设置为准，不要直接把默认值当作源视频参数。

保留原视频与 `.mosp`，下一次从工程继续编辑。问题排查见 [FAQ](FAQ.md)。
