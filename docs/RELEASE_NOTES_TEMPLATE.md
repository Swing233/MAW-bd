# 发布说明模板

以 [原作者 v1.7.0 发布说明](https://github.com/Moyf/moys-asr-workflow/releases/tag/v1.7.0) 的结构为参考：下载入口 → 使用步骤 → 教程链接 → 分类更新。只描述 MAW-bd 实际提供的功能，不照搬上游其他平台、供应商或已删除功能。

每次发布整合上一个正式版之后的全部变化。安装文件、版本和链接须核对实际发布资产。不要加入技术详情、测试统计或文件校验段落；保留原作者署名。没有内容的更新分类省略。

```markdown

- **macOS 🍎（Apple Silicon）**
  - 首次安装：[完整安装包](<实际资产链接>)
  - 已安装 <支持增量的基础版本>：可在应用内选择增量更新。

## 如何使用

1. 下载完整包并解压，将 MAW-bd.app 放入「应用程序」。
2. 打开应用，选择视频或音频。
3. 识别后按需进行文稿校对。
4. 打开字幕编辑器，保存工程并导出字幕。

已有 SRT 时可使用「MP4 + SRT 直接编辑」。
```
