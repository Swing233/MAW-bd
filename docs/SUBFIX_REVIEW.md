# SubFix 字幕规整功能调研

检查版本：2026-10-10，commit `02fe0985969ef51482a0d49bc4916d30e1acc39a`。仅阅读公开源码，未执行或复制其代码。

## 实际功能

“规整字幕长度”指时间轴规整，不是修改字数或英文大小写。主入口是 [run_normalize_subtitle_length](https://github.com/HooperH/SubFix/blob/02fe0985969ef51482a0d49bc4916d30e1acc39a/SubFix.lua#L19186)，两项可分别开关：

1. 字幕音频对齐：找到达芬奇时间线的音频源，按小批次对已有字幕做 Qwen 强制对齐，得到候选起止时间；可疑片段再以小窗口复核，只有更可靠的结果才移动时间。
2. 消除空隙：按时间排序，在正空隙不超过约两秒（`round(fps * 2)` 帧）时，将前一条结束贴到下一条开始；不修改文字，不合并字幕。保存快照支持撤销，用户之后写回达芬奇时间线。

[保护与复核实现](https://github.com/HooperH/SubFix/blob/02fe0985969ef51482a0d49bc4916d30e1acc39a/SubFix.lua#L12005)包含文本匹配、置信度、位移上限、顺序、邻接空隙、音频范围和最小时长检查；并统计保持原位、前移、后移、拒绝原因，写诊断记录。不要把它简化为按响度吸附：音乐、环境声、多人语音都会误导响度边界。

## MAW-bd 能否集成

可以独立实现同类功能。当前“消除字幕空隙”已覆盖其第二部分，默认最大 200ms、可自定义、预览和撤销；不用照搬它约两秒的阈值，避免跨较长停顿持续展示字幕。

第一部分尚未接入编辑器。建议作为明确由用户启动的“按音频校准时间”，与 LLM 校对分开：

- 复用本应用已安装的 Qwen ForcedAligner，输入最终字幕文字及本地音频。用工程稳定 ID 匹配结果，不能依赖数组下标随排序变化。
- 优先从原时间附近的小窗口开始，保留足够上下文；有真实可靠 items 的字幕默认不动，仅处理导入 SRT、估算时间或用户指定范围。
- 产生独立候选预览，显示原/新起止时间和移动量；拒绝低置信度、超范围、顺序反转、重叠和过短片段。没有可信置信度数据时不得虚构分数，只作为待确认建议。
- 字幕文字、顺序、数量保持不变；若用户采用音频时间校准，则按新的真实对齐时间更新 items，并保留原时间用于撤销。毫秒继续为兼容字段，帧工程按当前 fps 同步投影。
- 不在 ASR 完成或 LLM 校对后自动执行。手动时间校准允许修改时间，但 Manuscript/LLM 仍严格禁止改时间。
- 对长视频分批、取消不部分覆盖、试听预览、失败回退原工程；测试真实时间、口误、即兴、静音、背景音乐、重叠发言、中英文、字幕文本已校对和旧工程。
