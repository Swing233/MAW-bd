# 从视频到字幕：第一次使用 MAW-bd

这份教程带你完成一次字幕制作：安装应用 → 识别语音 → 校对文字 → 编辑字幕 → 导出。

> 本文对应当前开发版本。正式包的功能以对应版本发布说明为准；1.7.0 的校对建议需要在编辑器采用，后续开发版默认直接应用校对结果。

## 1. 安装并打开

从 [下载页面](https://github.com/Swing233/MAW-bd/releases) 选择 macOS Apple Silicon 完整安装包，解压后将 `MAW-bd.app` 放入「应用程序」，双击打开。

应用已包含 FFmpeg / FFprobe。首次使用本地识别时，会准备运行环境并下载模型，预留足够磁盘空间并保持网络连接。

首次打开被 macOS 阻止时，参见 [常见问题](FAQ.md)。

## 2. 选择操作方式

| 你已有的文件 | 从哪里开始 |
| --- | --- |
| 视频或音频，还没有字幕 | 「选择视频 / 音频」→「开始 ASR」 |
| 视频和 SRT | 「MP4 + SRT 直接编辑」 |
| `.mosp` 或旧 `.json` 工程 | 「导入工程打开」 |
| 想先打开编辑器 | 「打开字幕编辑器」 |

编辑器可以随时打开，无需先完成识别或修订。

## 3. 识别语音

1. 点击「选择视频 / 音频」。
2. 选择识别方式。默认使用本地 Qwen3-ASR 1.7B；首次可先点「下载 / 检查本地模型」。
3. 使用云端识别时，填写自己的百炼 API Key 并保存配置，再选择云端 Qwen 模型。
4. 点击「开始 ASR」，等待完成，查看界面的输出工程和 SRT 路径。

模型准备时可能没有精确百分比；长音频识别会显示分块进度。是否完成，以任务状态和输出文件为准。

## 4. 校对文字（可选）

有原文稿时，在「修订字幕」中添加参考文稿。支持 TXT、Markdown、DOCX 和直接粘贴，不支持 PDF。

填写 DeepSeek API Key，点击「开始修订」。当前开发版默认应用校对结果，并保留修改前文字供编辑器查看和恢复。校对只改文字，不改变字幕条数、顺序和时间。

**实际说出的内容优先。** 文稿用于辅助判断错字、人名和术语，不能把现场发挥替换成原稿。

没有 API Key 时，可使用「生成提示词并复制」到外部模型进行校对，再导入返回的 SRT；导入前检查字幕序号和时间码是否保持一致。

## 5. 编辑字幕

打开工程后，边播放边检查文字与时间：

- 双击字幕修改文字。
- 在列表或波形空白处拖动，框选多条字幕。
- 悬停字幕查看切割线，按分割快捷键拆分；不悬停字幕时按播放位置切割。
- 使用「审阅」筛选 LLM 修改、数字、英文、标点或空格。
- 选中字幕后，使用「文本处理」统一数字和英文大小写。

详细操作见 [字幕编辑器指南](EDITOR_GUIDE.md)。

## 6. 保存并导出

先用 `Cmd+S` 保存 `.mosp` 工程，再导出交付文件。

| 文件 | 用途 |
| --- | --- |
| `.mosp` | 下次继续编辑，保留校对信息与工程设置 |
| `.srt` | 通用字幕文件，只包含最终字幕和时间 |
| `.fcpxml` | 导入 Final Cut Pro，需选择合适分辨率与帧率 |
| `.mopeaks` | 波形缓存，可重新生成，不能当作字幕工程 |

保留原视频和工程。以后修改时打开 `.mosp`，不必重新识别。
