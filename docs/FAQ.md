# MAW-bd 常见问题

首次使用见 [完整教程](WORKFLOW.md)，编辑操作见 [编辑器指南](EDITOR_GUIDE.md)。本文对应 1.8.0。

## 下载哪个文件？

搭载 Apple 芯片的 Mac 下载 macOS arm64 完整 ZIP。不要将增量 ZIP 当作安装包，也不要下载 GitHub 自动生成的 Source code 作为应用。

## macOS 提示无法验证开发者，怎么办？

确认文件来自 [本项目发布页面](https://github.com/Swing233/MAW-bd/releases)，完整解压后放入「应用程序」。尝试打开一次后，在「系统设置 → 隐私与安全性」查看是否提供「仍要打开」，按系统提示确认。操作参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果提示应用损坏或文件不完整，先重新下载完整包。不要关闭整个系统的安全保护。当前应用尚未经过 Apple 公证。

## 没安装原版 MAW，可以本地识别吗？

可以。当前完整应用会准备专用运行环境；首次点击「下载 / 检查本地模型」需要联网下载模型及依赖。后续复用缓存，不需要安装另一份 MAW。

## 模型下载一直没有进度，或者连接超时？

先查看日志是准备运行环境还是下载模型。模型较大，检查剩余磁盘空间与网络。下载缺少文件时默认尝试国内源，失败再回退官方源；已完成的缓存会复用。

如果长时间报相同错误，停止任务后重试，并保留最后一条完整错误。已经下载完整的 Qwen 缓存会直接离线加载。

## 本地识别出现乱码或整段字幕很长？

1. 检查版本，1.7.0 修复了 Mac 本地 Qwen 识别乱码的问题。
2. 试听原媒体，确认选择了需要识别的人声。
3. 对整段异常字幕，查看日志是否提示字词时间码缺失或无效。没有可靠时间码时，不能把平均分配的时间当作真实停顿。
4. 保存工程并提供异常字幕、版本号和错误日志，便于排查；不要提交 API Key 或私人素材。

文稿校对不会重新断句。调整分段应在编辑器处理，拆分后试听检查时间。

## 云端 ASR 或 DeepSeek 提示 Key 错误？

两者使用各自的 Key：云端 ASR 使用百炼 Key，校对使用 DeepSeek Key。在配置区重新填写并保存，同时检查服务额度。向他人反馈时遮住密钥。

## 为什么导入工程后没有波形？

工程并不包含整段视频。检查媒体是否还在原路径，必要时重新选择媒体。只有 SRT 或 `.mopeaks` 无法还原视频。

本机编辑器会加载或生成波形缓存，大文件需要等待。已有视频和 SRT 时，可从启动器「MP4 + SRT 直接编辑」准备波形，避免浏览器整段解码。

## 已有 SRT，必须再识别一次吗？

不需要。点击「MP4 + SRT 直接编辑」，视频旁的同名 SRT 会在首次创建工程时自动载入。没有同名 SRT 时，进入编辑器后手动导入。

已存在 `.maw-edit.mosp` 时继续打开该工程，避免覆盖修改。如果要使用另一份 SRT，在编辑器中导入前先保存当前工程。

## LLM 修改后能恢复原文吗？

1.8.0 默认直接应用校对结果。在「审阅 → LLM 修改」找到对应字幕，悬停校验徽标查看差异，选择保留原文。人工修改受保护。

1.7.0 的旧流程先保存建议，需要在编辑器采用；安装版本不同，行为会有区别。

## 转换数字后为什么还显示在数字筛选里？

当前筛选结果在修改后保持显示，便于查看转换效果。切换或重新选择筛选条件，会按当前文字重新计算。

## FCPXML 导入 Final Cut Pro 失败？

从当前版本重新导出，并选择与目标工程一致的帧率和分辨率。记录 Final Cut Pro 的完整报错和软件版本；不要只改变文件扩展名。

## 更新下载慢或失败？

切换更新页面的下载线路重试。增量包不可用时选择全量更新，也可从发布页手动下载完整包。安装前保存工程，应用会退出后完成替换，不是在运行中直接替换。

## 反馈问题时需要什么？

到 [GitHub Issues](https://github.com/Swing233/MAW-bd/issues) 提供应用版本、macOS 版本、重现步骤和错误截图。提交截图前遮住 API Key、私人文件路径和不希望公开的字幕内容。不要上传 `.env`。
